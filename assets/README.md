Linux Skill Assessment - Static Website
========================================

Project files in this directory:

- index.html          # Home page with student information form
- quiz.html           # Exam interface with 25 MCQ questions  
- result.html         # Results page with PASS/FAIL and PDF download
- css/
  └── style.css       # Complete styling (responsive, professional)
- js/
  ├── questions.js    # 25 predefined Linux/RHCSA questions + shuffle utilities
  └── app.js          # All application logic (navigation, scoring, PDF)
- assets/
  └── README.md       # This file

This is a frontend-only static website requiring no backend, database, or server-side processing.
